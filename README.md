# Muziek & Media Lab

Een rustig, leerlinggericht prototype voor het atelier **Muziek & Media** van OV+ Egmont & Hoorn.

## v0.1
- zes routes: Explorer, Musician, Producer, Designer, Media Maker en Coder
- drie soorten uitdaging: Explore, Create en Deep Dive
- vijf zelfstandige startmissies
- responsive voor Chromebook en smartphone
- OV+ Helder-vormgeving
- geen accounts of persoonsgegevens

Het Lab is geen niveausysteem. Een leerling kan per domein een andere route of uitdaging kiezen.
